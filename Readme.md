# College Event Management System

## Features

* View upcoming college events
* Display event date and venue
* Student event registration
* Select an event for registration
* Enter student name and email

## Technologies Used

* HTML

## Installation

1. Download the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Usage

1. Open the `index.html` file.
2. View the list of upcoming events.
3. Select an event from the registration form.
4. Enter the student name and email.
5. Click the **Register** button.
